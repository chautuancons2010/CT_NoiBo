# Dashboard override

This file overrides the master only for `/dashboard` and role-specific dashboard compositions.

- Keep the greeting and date contextual, compact and subordinate to operational data.
- Present the permission-filtered module launcher before secondary widgets.
- KPI cards show value, label and operational context. Do not invent data.
- Use line charts for time trends and bullet/progress presentation for target comparison.
- Preserve a visible textual/table fallback for charts.
- Place attention queues above recent history; personal notes and todos remain secondary.
- Desktop uses four KPI columns where space permits; tablet uses two; mobile uses two compact columns or one when content length requires it.
- Motion remains limited to hover/focus/press feedback and loading states.
